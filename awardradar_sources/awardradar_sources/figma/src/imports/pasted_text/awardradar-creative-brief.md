==============================================================================
AWARDRADAR V2 — CREATIVE DIRECTOR PASS
==============================================================================

Forget every previous homepage iteration.

Do NOT refine the current design.

Delete assumptions.

Start from first principles.

You are no longer designing a travel website.

You are designing a premium software product.

Think:

• Apple Hardware
• Leica
• Bang & Olufsen
• Linear
• Arc Browser
• Stripe

Never think:

• Booking.com
• Skyscanner
• Kayak
• Google Flights
• Expedia
• Generic SaaS dashboards

The homepage must feel timeless.

==============================================================================

01. THE PRODUCT

AwardRadar is not selling travel.

AwardRadar is not selling flights.

AwardRadar is not selling miles.

AwardRadar provides confidence.

The interface should feel calm, precise and inevitable.

Never loud.

Never playful.

Never "look at me".

==============================================================================

02. REMOVE VISUAL WEIGHT

Reduce:

• borders
• boxes
• separators
• outlines
• shadows
• decorative UI

Increase:

• whitespace
• rhythm
• proportion
• breathing room

Every element should feel intentional.

==============================================================================

03. TYPOGRAPHY

Inter only.

Allowed weights:

300
400
500
600

No bold headlines.

No multiple font families.

No decorative typography.

Hierarchy comes from:

• spacing
• rhythm
• scale
• contrast

—not from different fonts.

==============================================================================

04. HERO

Use exactly this copy.

AwardRadar

TRAVEL DECISION INTELLIGENCE

We don't tell you what to book.

We help you understand

why.

Do not add marketing copy.

Do not explain features.

Do not add subheadings.

The homepage establishes trust.

Nothing else.

The word "why." is the emotional destination.

Give it subtle visual emphasis.

Not orange.

Not bold.

Not oversized.

Simply impossible to ignore.

==============================================================================

05. THE GLOBE

The globe is NOT decoration.

The globe is the emotional centre of the interface.

It must feel:

• enormous
• alive
• cinematic
• premium
• physically present

Requirements:

• extremely slow rotation
• Earth at night
• warm golden city lights
• subtle atmospheric limb glow
• soft volumetric lighting
• deep blue-black oceans
• almost invisible continents
• no neon
• no sci-fi
• no visible gradients

The globe must continue beyond the viewport.

Never show the complete sphere.

It should feel infinitely large.

==============================================================================

06. CITY LIGHTS

Remove every orange ring.

Never highlight cities with circles.

Cities glow naturally.

Nothing flashes.

Nothing screams.

AwardRadar observes.

It never shouts.

==============================================================================

07. SEARCH INSTRUMENT

Do NOT design a form.

Design a precision instrument.

Imagine:

• Leica lens
• Bang & Olufsen amplifier
• Apple aluminium chassis

One continuous object.

No nested cards.

No floating pills.

No toy-like controls.

Very subtle dividers.

The search button belongs inside the instrument.

The entire object should feel machined.

==============================================================================

08. LAYOUT

Avoid perfect symmetry.

Move the editorial content slightly left.

Move the globe further right.

Create tension.

Allow asymmetry.

The globe should dominate.

The copy should breathe.

==============================================================================

09. LOGO

Restore the classic AwardRadar logo.

Never write:

AWARDRADAR

Keep:

AwardRadar

with the orange "Radar".

Small.

Elegant.

Confident.

==============================================================================

10. NAVIGATION

Top:

About

Methodology

Sign in

Bottom:

Privacy

Imprint

Accessibility

Theme

@AwardRadar

Footer text must remain readable.

Do not reduce contrast too much.

==============================================================================

11. LIGHT MODE

Do NOT invert dark mode.

Create a completely independent light experience.

Use:

• warm white
• stone
• slate
• subtle depth
• soft shadows

The light theme should feel like premium paper.

Never generic white software.

==============================================================================

12. MOST IMPORTANT RULE

If an element still looks like a travel website,

delete it.

If an element still looks like AwardRadar 1.x,

delete it.

If an element exists only because websites usually have it,

delete it.

Do not iterate.

Recompose.

The homepage should feel like a product people remember after closing the browser.

==============================================================================

FINAL OBJECTIVE

When someone opens AwardRadar for the first time, they should immediately think:

"This doesn't feel like another travel website.

It feels like a beautifully engineered decision instrument."

That is the benchmark.
