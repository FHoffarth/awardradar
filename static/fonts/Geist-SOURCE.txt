Files used:
  Geist-Variable.woff2      variable weight axis, covers 400/500/600/700
  GeistMono-Variable.woff2  variable weight axis, technical/code contexts

Only the two upright variable WOFF2 files required by AwardRadar are bundled.
The variable faces replace multiple static weights, so no synthetic bold is
needed and the total payload stays below the previous static-weight set.
The npm package itself is not a project dependency; the files are vendored
here and self-hosted, with no external font CDN request at runtime.
