# Mission

AwardRadar exists to help travelers make better award booking decisions.

The goal is not to show more award availability.

The goal is to answer one simple but difficult question:

> Should I book this?

AwardRadar combines award availability, cash prices, taxes and surcharges, loyalty program intelligence, sweet spot detection, traveler preferences, risk signals, and alternatives, then turns them into a clear recommendation.

AwardRadar is not an award search engine.

AwardRadar is a booking decision engine.

Tagline:

> Know when to book with miles.

# Category Definition

Competitors show data.

AwardRadar makes the decision legible.

# Mission Filter

1. Does this help answer "Should I book this?"
2. Does it reduce mental load?
3. Does it increase the likelihood of a better decision?

If not, deprioritize.

# North Star Metric

Successful Booking Decisions

Definition:

A user made a concrete travel decision with AwardRadar assistance.

Examples:

- Book miles
- Book cash
- Set alert
- Change route
- Change date
- Decide not to book

# Product Principles

- Recommendation over information
- Clarity over completeness
- Fewer but better choices
- Trust over engagement
